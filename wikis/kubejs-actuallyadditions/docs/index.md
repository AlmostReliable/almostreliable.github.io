# Getting Started

> [!WARNING] NOTE
> This wiki is for KubeJS Actually Additions for Minecraft 1.21.1.

This mod is an add-on for [KubeJS](https://github.com/KubeJS-Mods/KubeJS) to add support for [Actually Additions](https://github.com/Ellpeck/ActuallyAdditions). It offers easy creation of new recipes, modification of existing ones, and an event to react to finished Empowerer recipes.

All recipe types of Actually Additions are supported. Recipes are validated when they are created, so mistakes like too many outputs or fluid amounts the machine can't hold show up as errors in the log upon `/reload`ing or restarting the game.

Actually Additions measures energy in Crystal Flux (CF). CF is just another name for Forge Energy (FE), so 1 CF equals 1 FE. All energy values on this wiki use this unit. Unless a page says otherwise, time is measured in game ticks. 20 game ticks are one second.
